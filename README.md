## 📦 Local Development

### Prerequisites
- Node.js 18+
- npm or pnpm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/<your-username>/background-animation-collection.git

# Navigate into project directory
cd background-animation-collection

# Install dependencies
npm install

# Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the Vite port) to view it in the browser.

## 🛠️ Production Build & Deployment

### Build the Static Site
```bash
npm run build
```
This outputs production-optimized static files to the `dist/` folder.

### Deploying to GitHub Pages
1. Install `gh-pages`:
   ```bash
   npm install -D gh-pages
   ```
2. Add deploy scripts to `package.json`:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
3. Run:
   ```bash
   npm run deploy
   ```

### Deploying to Vercel / Netlify
- Push the repository to GitHub.
- Import the repo in [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
